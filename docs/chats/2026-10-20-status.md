## How to start the Astro dev server

From the `site/` directory (not the repo root):

```bash
cd site
npm run dev -- --background
```

This invokes `astro dev --background` (Astro's native background mode). The root `npm run dev`
is the **showcase** Vite server — that's why `--background` failed earlier ("Unknown option
`--background`"): Vite doesn't have that flag, Astro does.

Manage it:

```bash
cd site
npm run astro -- dev status   # check if it's running
npm run astro -- dev logs      # tail the log
npm run astro -- dev stop      # stop it
```

(Or call the local binary directly: `site/node_modules/.bin/astro.cmd dev {status|logs|stop}`.)

Notes:

- It serves the **live site** at http://localhost:4321 — the local equivalent of
  https://ui.sakhalabs.com. Hot-reloads content and config changes.
- It's managed by Astro's background daemon (not a shell process), so it survives terminal
  closes; stop it with `astro dev stop`.
- If you ever need to rebuild the library first (the site imports `@sakhalabs/ui/styles.css`
  from `packages/ui/dist/`), run `npm run build:ui` from the repo root.
